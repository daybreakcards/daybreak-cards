Backend

Card search runs free, directly against pokemontcg.io — no API key or cost. Adding a card to your catalog writes to Airtable through your Netlify Function (add-to-inventory). Make sure AIRTABLE_API_KEY, AIRTABLE_BASE_ID, and AIRTABLE_TABLE_NAME are set in your Netlify site's environment variables — no ANTHROPIC_API_KEY needed for this version.

Want photo-based scanning instead of typing names? That needs a paid Anthropic API key server-side — ask if you'd like that added back in later.
